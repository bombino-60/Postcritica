# Attribuzione degli asset

Ogni asset del repository (icone, immagini, font, suoni) deve avere una voce qui: percorso, titolo,
autore/creatore, origine, licenza, data, modifiche. Gli asset senza voce non si committano.

Le icone disegnate in codice sono considerate lavoro originale.
